# pka2xml brand

**Open the file. Understand the network.**

pka2xml is a small, transparent workshop for the networks inside your files. Its identity keeps the original lightning symbol and gives it a glass packet, open code brackets, and one warm connection point. The mark represents clarity, care, and an understandable path between formats.

## Palette

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#17343B` | Primary text and deep surfaces |
| Sea glass | `#26766D` | Primary actions and active controls |
| Mist | `#BCE6DA` | Selected surfaces and soft highlights |
| Blush | `#E9AD9F` | Warm details and connection points |
| Paper | `#F5F4ED` | Quiet canvas |

Use ink on light surfaces. Blush and mist are accents, not small text colors. Glass effects must keep controls readable without backdrop-filter; focus and status must remain visible without color alone.

## Assets

- `pka2xml-mark.svg`: full-color mark, self-contained vector.
- `pka2xml-mark-mono.svg`: one-color mark using `currentColor`.

Allow at least one sixth of the mark's width as clear space. Use the simplified monochrome version where gradients are unsuitable. Keep the project name lowercase: **pka2xml**. Do not imply affiliation with Cisco or endorsement by Packet Tracer.

## Voice

Use calm, direct language. Explain the next action when a conversion fails. Celebrate a saved result gently. Describe local processing accurately and disclose build limitations. Let the interface feel friendly without hiding what the tool does.
