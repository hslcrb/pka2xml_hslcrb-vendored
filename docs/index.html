pka2xml.

The transparent workshop

파일을 열고,
네트워크를 이해하다.

PKA·PKT와 XML을 오가는 작은 작업실입니다. 새 브라우저 앱은 파일을 기기 안의 WebAssembly 워커에서 변환합니다. 데스크톱과 명령행 도구도 함께 제공합니다.

실행 방법 보기 ↗ 소스 살펴보기 ↗

이 문서 페이지는 파일을 받거나 서버로 전송하지 않습니다. 제품 소개페이지는 web/ 앱의 /, 변환 작업실은 /workbench에서 제공됩니다. 과거 원격 업로드 인터페이스는 종료했습니다.
