# Workshop Sans UI

A renamed UI subset of Pretendard Variable 1.3.9 by Kil Hyung-jin, distributed under the SIL Open Font License 1.1 in `OFL-Pretendard.txt`. Original source: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9

The subset contains the union of the desktop and web interface characters at this revision, ASCII/Latin-1, general punctuation, and Korean Jamo. Variable weight support is retained. Family/PostScript metadata is renamed **Workshop Sans UI / WorkshopSansUI** to respect the reserved Pretendard name. Original copyright and license metadata remain.

Arbitrary file names and converted text use the system font fallback when they contain characters outside this interface subset. When adding UI text, update the subset from the official original, or use an appropriately licensed complete local font.
